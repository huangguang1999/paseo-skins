QUICK START

复制给 Agent，剩下交给它

Agent 只会读取公开 Skill、主题 JSON 与图片；所有操作仍在你的电脑完成。

  1. 01

    选择皮肤

    在主题卡片上点击“复制给 Agent”。

  2. 02

    粘贴给 Agent

    任务内含 Skill 地址、主题清单与安全约束。

  3. 03

    自动应用与验收

    Agent 运行 doctor、watcher 和 verify；遇到运行中任务会安全停下。

SAFETY BY DEFAULT

换外观，不动 Paseo 本体

  • 不改安装包不 patch Paseo、app.asar 或代码签名。
  • 只认声明式主题远程主题只能包含 JSON 与 PNG/JPEG，不执行脚本。
  • 仅限本机连接CDP 固定绑定 127.0.0.1，不暴露给局域网。
  • 随时还原停止 watcher 后运行 reset，恢复原生样式。
