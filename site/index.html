SAFETY BY DEFAULT

换外观，不动 Paseo 本体

  • 不改安装包不 patch Paseo、app.asar 或代码签名。
  • 只认声明式主题远程主题只能包含 JSON 与 PNG/JPEG，不执行脚本。
  • 仅限本机连接CDP 固定绑定 127.0.0.1，不暴露给局域网。
  • 随时还原停止 watcher 后运行 reset，恢复原生样式。
