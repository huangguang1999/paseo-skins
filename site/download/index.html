COMMAND-LINE TOOL

不装客户端，
一条命令换肤。

面向程序员的开源 CLI。它负责主题完整性、Paseo 连接、持久 watcher 和一键还原；网页只负责预览与制作。

QUICK START

应用热门晨雾山水

需要 macOS、Paseo.app 与 Node.js 22+。命令会校验公开目录、Theme v2 清单和原图 SHA-256，再安装当前用户的持久 Guardian。

npx --yes github:huangguang1999/paseo-skins apply morning-mist --persist

CORE COMMANDS

完整工作流

paseo-skin list

列出公开目录中的主题。

paseo-skin apply <theme-id> --persist

持久应用主题并自动恢复。

paseo-skin inspect --theme …

离线检查清单与图片。

paseo-skin create --image …

从图片制作主题包。

paseo-skin verify --screenshot …

验证真实 renderer 并保存截图。

paseo-skin autostart uninstall

移除自动恢复配置。

paseo-skin reset

恢复原版 Paseo 样式。

为什么不是客户端？

本项目不需要另一个常驻 GUI。GitHub Pages 提供无权限的预览和 Studio；CLI 是可审查、可脚本化的本机执行层。两者都不会上传你的主题图片。

关闭终端也会自动恢复

快速开始命令通过可见的 --persist 显式安装当前用户的 macOS LaunchAgents。关闭终端、退出 Paseo 或重启电脑后都会自动恢复；可用 autostart uninstall 完整移除。
